M.O.D. THE CABANA CAFE — WEBSITE DEMO
=====================================

Files:
- index.html: responsive single-page website demo.

HOW TO OPEN ON YOUR MAC:
1. Unzip this folder.
2. Open VS Code.
3. Choose File > Open Folder... and select MOD_The_Cabana_Cafe_Website.
4. Click index.html in the left sidebar.
5. To preview: easiest is to double-click index.html in Finder; it opens in your browser.
   You need an internet connection for the sample photos and Google Fonts.
